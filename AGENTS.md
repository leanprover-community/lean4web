# AGENTS.md

## Setup commands

- `npm ci`
- `npm run build` runs everything, including `npm run build:projects`, which
  defines how the sample Lean projects are updated.

## Coding Style

- `npm run lint`
- `npm run fmt`

## Commits and Merge Requests

- do not add the agent as a coauthor of the commit. Concretely, do not add `Co-authored-by` to denote which agent was involved.
